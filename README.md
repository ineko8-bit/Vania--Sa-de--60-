# Saúde 60+

MVP acadêmico de saúde digital para pessoas idosas, familiares e cuidadores. Objetivo: apoiar a organização de medicamentos e horários por uma interface simples e acessível.

## Funcionalidades previstas
- Cadastro de medicamento, dose e horário
- Consulta de medicamentos
- Avisos textuais sobre horários

## Como executar
Abra `index.html` no navegador.

## Limitações
Protótipo demonstrativo, com armazenamento local neste navegador. Não envia notificações externas, não substitui orientação médica e não deve receber dados reais sensíveis em computadores compartilhados.
