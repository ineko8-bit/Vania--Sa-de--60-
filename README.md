# Vania--Sa-de--60-
Projeto acadêmico de desenvolvimento de um aplicativo voltado à promoção da saúde, autonomia e qualidade de vida de pessoas idosas. O Saúde 60+ propõe uma interface acessível e intuitiva para o gerenciamento de medicamentos, lembretes e acompanhamento de cuidados com a saúde, oferecendo apoio a idosos, familiares e cuidadores.
